1. 개요

'롤 투기장(LoL Arena)' 디스코드 봇 및 액티비티(이하 '서비스')는 봇이 설치된 디스코드 서버에서 게임을 시작할 때 온라인인 멤버 가운데 6명을 뽑아 진행하는 League of Legends 3:3 사설 친선 대전을 지원하기 위한 비상업적 소규모 서비스입니다.

본 방침은 서비스 이용 과정에서 수집되는 정보의 항목, 이용 목적, 보관 기간 및 이용자의 권리에 대해 설명합니다.

2. 수집하는 정보

서비스는 목적 달성에 필요한 최소한의 정보만을 처리합니다.

  • 디스코드 OAuth 계정 정보 (`identify` 범위): Discord 사용자 고유 ID, 사용자명(Username), 전역 표시 이름(Global Name), 아바타 해시(Avatar Hash).
  • 디스코드 서버(길드) 정보: 서버 내 별명(Guild Nickname)과 온라인 상태(새 판을 시작할 때 온라인인 사람 가운데 6명을 뽑기 위한 목적).
  • 게임 진행 및 전적 정보: 게임 판 번호, 시즌 번호, 경기 진행 시각, 팀 구성(1팀/2팀 배치), 선택한 챔피언 목록, 경기 승패 결과, 판정 번복 이력.

3. 정보의 이용 목적

  • 팀 편성 및 게임 진행: 6인의 참가자를 3:3 두 팀으로 배정하고 실시간 챔피언 픽 차례를 제어하기 위해 사용합니다.
  • 전적 기록 및 통계 제공: 승패 결과와 팀 조합 통계를 계산하여 참여자 간 대전 기록을 유지합니다.
  • 전적 및 표시 이름 공개: 게임 기록(판 번호, 참여자 표시 이름, 픽한 챔피언, 승패 결과)은 공개 웹페이지인 arena.hansoljj.com 대시보드에 게시됩니다.
  • OAuth 토큰 및 실시간 세션: 인증에 사용된 Discord OAuth 토큰과 웹소켓 연결 세션은 서버 메모리에만 1시간 이내로 임시 유지되며, 디스크나 데이터베이스에 영구 저장하지 않습니다. 액티비티를 열었지만 게임에 뽑히지 않은 사람(관전자)의 계정 정보는 접속하는 동안에만 메모리에 두고 저장하지 않으며, 전적에는 게임에 뽑힌 6명만 기록됩니다.

4. 정보의 보관 및 제3자 제공

  • 보관 장소 및 기간: 경기 전적 기록 데이터는 서비스 운영자의 개인 서버에 보관되며, 백업을 위해 누구나 볼 수 있는 공개 GitHub 저장소(github.com/HANSOLJJ/lol_arena)에도 올라갑니다. 서비스를 운영하는 동안 보관합니다.
  • 상업적 활용 금지: 수집된 정보를 판매하거나 광고 마케팅, 프로파일링 등 상업적 목적으로 일절 사용하지 않습니다.
  • 제3자 제공: 운영자는 원칙적으로 이용자의 정보를 외부에 제공하거나 위탁하지 않습니다. 단, 서비스 구동을 위한 기술적 인프라로 다음 서비스와 연동됩니다.
    • Discord: 사용자 신원 확인 및 액티비티 샌드박스 실행.
    • Riot Games Data Dragon: 리그 오브 레전드 공식 챔피언 초상화 이미지 로드.
    • Cloudflare: 도메인 DNS 라우팅 및 웹 보안 프록시.

1. Overview

The "LoL Arena" Discord bot and Discord Embedded Activity ("Service") is a non-commercial, small-scale utility designed exclusively for running 3v3 League of Legends custom matches in Discord servers where the bot is installed, picking 6 players from the members who are online when a match starts.

This Privacy Policy outlines the types of data collected, how it is used, where it is stored, and how users can request data deletion.

2. Information We Collect

The Service processes only the minimum data required to organize custom matches.

  • Discord OAuth Identity Data (`identify` scope): Discord User ID, username, global display name, and avatar hash.
  • Discord Guild Data: Server nickname and online status (used only to pick 6 online members when a new match starts).
  • Match & Gameplay Data: Match/round number, season identifier, game timestamp, team rosters (Team 1 / Team 2), chosen champion IDs, win/loss outcome, and correction/reverse logs.

3. How We Use Information

  • Match Orchestration: Dividing players into two teams of 3 and orchestrating the live sequential champion pick phase.
  • Leaderboards & Analytics: Aggregating match statistics, player win-rates, and team synergies.
  • Public Match History: Match records and player display names are publicly viewable on the match history dashboard at arena.hansoljj.com.
  • Ephemeral Tokens & Sessions: OAuth access tokens and active WebSocket session state exist exclusively in volatile server memory for less than 1 hour and are never persisted to disk or databases. Account data of people who open the Activity but are not picked for a match (spectators) is kept in memory only while connected and is never stored; only the 6 players picked for a match are recorded in the match history.

4. Data Storage and Third Parties

  • Storage & Retention: Historical match records are stored on the operator's personal server and are also backed up to a public GitHub repository (github.com/HANSOLJJ/lol_arena) that anyone can view. Records are kept for as long as the Service is operated.
  • No Commercial Exploitation: User data is never sold, leased, or utilized for advertising, monetization, or profiling.
  • Third-Party Infrastructure: No data is shared with third parties for commercial gain. Technical dependencies include:
    • Discord: User authentication and Activity SDK handshake.
    • Riot Games Data Dragon: Champion square portrait retrieval.
    • Cloudflare: DNS routing and reverse-proxy protection.

5. User Rights and Deletion Requests

Users have the right to request access to, correction of, or deletion/anonymization of their match history and associated display names.

Upon request sent to the contact address below, the operator will remove the requested display name from the dashboard and the current files of the repository, or replace it with an anonymous identifier (e.g., "Player X"). Earlier versions may remain in the public GitHub repository's commit history.
