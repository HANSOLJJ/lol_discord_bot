# 옛 전적 대시보드 5개 탭 React 이관 실행 계획

작성일: 2026-09-28.
이 문서는 옛 index.html의 5개 탭(개인, 2인 시너지, 3인 시너지, 챔피언, 3:3 매치업)을 `activity/src/dashboard/`의 React·TypeScript 대시보드로 이관하기 위한 상세 구현 계획서이다.

---

## 1. 5개 탭 기능 및 사양 상세 정의

### 1-1. 공통 컨트롤 및 상태 규칙
- **기간 필터 (Period)**: 전체, 시즌별(최신 시즌에 '· 진행중' 표기), 세션별(S01 날짜 라운드). 탭을 전환해도 선택된 기간 필터는 유지된다.
- **인원 선택 칩 (Chips)**: 탭별 최대 선택 가능 인원 수(SEL_MAX)에 따라 칩의 동작이 달라진다.
  - `player`: 최대 1명
  - `pair`: 최대 2명
  - `trio`: 최대 3명
  - `champ`: 0명 (인원 선택 비활성화)
  - `matchup`: 최대 1명
  - `history` (대전 기록): 기존 규칙 유지 (다중 선택)
  - 최대 인원 도달 시 미선택 칩은 비활성화(disabled, opacity 0.35) 처리된다.
  - 1명 이상 선택 시 "초기화" 버튼이 노출된다.
  - 인원 선택 변경 시 테이블 정렬 상태는 기본값으로 초기화된다.
- **최소 판수 슬라이더 (Min Games)**:
  - 1부터 10까지 슬라이더 (기본값: 1).
  - 대전 기록 탭에서는 숨기고, 통계 탭(개인, 2인 시너지, 3인 시너지, 챔피언, 3:3 매치업)에서 표시한다.
- **테이블 공통 정렬 및 동률 처리**:
  - 컬럼 정렬 클릭 시: 같은 열 재클릭이면 오름차순/내림차순 토글, 다른 열 클릭 시 숫자형 열(num: true)은 desc, 문자열/일반 열은 asc 기본.
  - 동률 처리: 1차 정렬 값이 같을 경우 `_n`(판수) 기준 보조 정렬 수행. 정렬 방향이 desc이면 판수가 많은 것이 먼저, asc이면 판수가 적은 것이 먼저 배치된다.
- **빈 결과 문구**:
  - 조건에 맞는 데이터가 없을 때: `"최소 판수 조건을 만족하는 데이터가 없습니다."` (colspan = 전체 열 수).
- **승률 및 금액 포맷**:
  - 승률: `(w / n) * 100` (n=0이면 0%). 막대 그래프 배경색은 `hsl(round(wr * 1.2) 62% 45%)`.
  - 번 돈(earnings): `(2 * w - n) * 0.5만`. 0 초과면 `+X만`(초록), 0 미만이면 `-X만`(빨강), 0이면 `0만`(중립 회색). 정수면 소수점 없음, 아니면 소수점 1자리.

### 1-2. 탭별 상세 스펙

#### [1] 개인 탭 (`player`, URL 해시 `#player` 및 `#personal`)
- **선택 제한**: 최대 1명.
- **하단 안내 문구**:
  `주력 챔프 TOP5는 승수 많은 순입니다. 초상화를 누르면 전적, 플레이어 이름을 누르면 챔피언별 상세를 볼 수 있습니다. '번 돈'은 선택한 기간의 승 +5,000원 / 패 -5,000원 정산입니다.`
- **A. 미선택 상태 (전체 플레이어 개요)**:
  - 대상: 6명 전체 목록.
  - 열 구성 (PC):
    1. 플레이어: 이름 + "챔프 ›" 링크 버튼 (클릭 시 드릴다운 진입).
    2. 판: 해당 기간 전체 판 수.
    3. 플레이 챔프 수: 해당 플레이어가 플레이한 고유 챔피언 수.
    4. 주력 챔프 TOP5: 승수 많은 순, 동률 시 판수 많은 순, 승률 높은 순으로 정렬한 상위 5개 챔피언 초상화 버튼 스트립 (초상화 클릭 시 툴팁 팝업).
    5. 승률: 승/패 텍스트 + 프로그레스 막대 + 정수 퍼센트 (유일하게 정렬 가능, 기본 desc).
    6. 번 돈: 순수익 포맷.
  - 정렬: 5번째 열(승률)만 정렬 가능 (`sortable: false` for others). 기본 정렬: 승률 내림차순.
  - 행 클릭: 행의 어디를 눌러도 해당 플레이어 드릴다운으로 진입 (버튼 클릭 제외).
  - 모바일(≤768px):
    - PC 테이블 숨김, 카드형 목록(`.player-mobile`) 표시.
    - 상단 헤더: "플레이어", 승률 정렬 토글 버튼(`▲`/`▼`), "번 돈".
    - 카드 내부: 플레이어 이름(링크), 승률/승패, 번 돈, 주력 챔프 TOP5 스트립, 판수, 플레이 챔프 수.
  - 챔피언 초상화 클릭 툴팁 (`champ-info`):
    - 클릭 시 해당 챔피언 이름, 전적(w승 l패), 승률(%), 총 판수 팝업.
    - ESC, 외부 클릭, 포커스 이동, 스크롤, 리사이즈 시 닫힘.
- **B. 인원 선택 상태 (플레이어별 챔피언 상세 드릴다운)**:
  - 상단 드릴다운 헤더 (`drillhead`):
    `{선택자} · {총 픽수}판 · 플레이 챔프 {고유 챔프수}종 · {승}승 {패}패` (최소 판수 필터와 무관하게 해당 인원의 전체 경기 집계).
  - 뒤로가기 버튼 (`backbar`):
    `‹ 전체 플레이어로` (클릭 시 선택 해제 및 이전 개요 정렬 상태 복원).
  - 열 구성:
    1. `{선택자} 챔프`: 초상화 + 챔피언 한글명.
    2. 픽: 해당 챔피언 플레이 횟수 (최소 판수 필터 적용).
    3. 승률: 해당 챔피언 승률 막대 및 승/패.
  - 정렬: 기본 2번째 열(픽) 내림차순. 모든 열 정렬 가능.

#### [2] 2인 시너지 탭 (`pair`, URL 해시 `#pair`)
- **선택 제한**: 최대 2명.
  - 0명 선택: 모든 2인 조합.
  - 1명 선택: 해당 인원이 포함된 모든 2인 조합.
  - 2명 선택: 해당 2명이 함께 뛴 조합.
- **하단 안내 문구**:
  `두 명이 같은 팀이었던 판의 시너지 승률. 인원은 2명까지(1명이면 그 사람의 모든 페어).`
- **열 구성**:
  1. 조합: 선택 인원 우선, 나머지 가나다순 (`선택자1 + 선택자2` 형식).
  2. 판: 함께 뛴 판 수 (최소 판수 필터 적용).
  3. 같은 팀일 때 승률: 승/패 텍스트 + 승률 막대 + 승률(%).
- **정렬**: 기본 3번째 열(같은 팀일 때 승률) 내림차순 (동률 시 판수 많은 순). 모든 열 정렬 가능.

#### [3] 3인 시너지 탭 (`trio`, URL 해시 `#trio`)
- **선택 제한**: 최대 3명.
  - 0명 선택: 모든 3인 조합.
  - 1~2명 선택: 선택된 인원들을 모두 포함하는 3인 조합.
  - 3명 선택: 해당 3명이 한 팀을 이룬 조합.
- **하단 안내 문구**:
  `세 명이 한 팀을 이뤘을 때 승률. 인원은 3명까지 — 2명만 골라도 그 2명이 낀 트리오가 전부 나옵니다.`
- **열 구성**:
  1. 조합: 선택 인원 우선, 나머지 가나다순.
  2. 판: 함께 뛴 판 수 (최소 판수 필터 적용).
  3. 같은 팀일 때 승률: 승/패 텍스트 + 승률 막대 + 승률(%).
- **정렬**: 기본 3번째 열(같은 팀일 때 승률) 내림차순 (동률 시 판수 많은 순). 모든 열 정렬 가능.

#### [4] 챔피언 탭 (`champ`, URL 해시 `#champ`)
- **선택 제한**: 0명 (인원 선택 칩 모두 disabled 처리, 초기화 버튼 숨김).
- **하단 안내 문구**:
  `챔프별 전체 픽 수·승률 (인원 선택 사용 안 함).`
- **열 구성**:
  1. 챔피언: 초상화 + 챔피언 한글명.
  2. 픽: 전체 픽 횟수 (최소 판수 필터 적용).
  3. 승률: 승률 막대 + 승/패.
- **정렬**: 기본 2번째 열(픽) 내림차순 (동률 시 판수 많은 순). 모든 열 정렬 가능.

#### [5] 3:3 매치업 탭 (`matchup`, URL 해시 `#matchup`)
- **선택 제한**: 최대 1명.
- **최소 판수 규칙**: `Math.max(2, minGames)` (2판 이상 반복된 대진만 표시).
- **하단 안내 문구**:
  `같은 3:3 구도가 2번 이상 반복된 경우만. 각 팀 아래는 그 팀 기준 전적. 인원 1명 선택 시 그 사람 팀이 왼쪽으로 고정돼 '내 팀 vs 상대팀'으로 읽힘.`
- **열 구성**:
  1. 판: 대진 판 수.
  2. A팀 (선택자 있을 경우 `{선택자} 팀`): 팀원 3명 이름 (선택자 우선, 가나다순) + 아랫줄 전적 (`{w}승 {l}패 ({wr}%)`).
  3. B팀 (선택자 있을 경우 `상대팀`): 상대 팀원 3명 이름 + 아랫줄 전적 (`{w}승 {l}패 ({wr}%)`).
- **정렬**:
  - 선택자 없을 때: 기본 1번째 열(판) 내림차순.
  - 선택자 1명 있을 때: 기본 2번째 열({선택자} 팀 승률) 내림차순.
  - 주의: A팀/B팀 열 헤더 클릭 시 기본 방향은 asc(문자열 열 기준 동작)이나 값은 승률 정렬.

## 2. 순수 계산 함수 모듈 설계 (`src/dashboard/lib/stats.ts`)

DOM 조작과 분리된 순수 함수 라이브러리를 작성한다.
- `calculateWinRate(w, n)`: 승률 반환.
- `calculateEarnings(w, n)`: 수익 수치 및 포맷팅 반환.
- `calculatePlayerStats(games, players)`: 6명 플레이어 전체 개요 집계.
- `calculatePlayerDrilldown(games, playerId, minGames)`: 특정 플레이어 챔피언별 집계 및 요약 헤더 수치 반환.
- `calculateComboStats(games, players, k, selectedIds, minGames)`: 2인/3인 시너지 조합 집계.
- `calculateChampStats(games, minGames)`: 챔피언 전체 픽/승률 집계.
- `calculateMatchupStats(games, players, focusPlayerId, minGames)`: 3:3 매치업 구도 집계 (canonical 키 기준 및 포커스 플립).
- `sortStatsRows(rows, sortKey, dir, secondaryKey)`: 동률 처리 포함 제자리 정렬/불변 정렬 함수.
