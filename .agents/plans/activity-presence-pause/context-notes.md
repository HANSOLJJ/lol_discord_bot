# 결정 기록 — activity-presence-pause (2026-09-29 사용자 결정)

- 표시 위치: 누가 들어와 있는지는 팀 칸 이름 옆 점 + 상단 "입장 n/6"으로 보여 준다. 픽 순서 목록에는 넣지 않는다.
- ready 기준: "입장"은 그 사람 화면이 첫 `state`를 실제로 그린 뒤 보낸 `ready`를 서버가 받은 시점이다.
- 전원 입장 후 5초: 참가자 전원이 입장하면 5초 카운트다운 뒤 픽 시작. 자동 최대 대기는 없다.
- 지금 시작: 끝내 안 들어오는 사람이 있으면 참가자 누구나 "지금 시작" 버튼으로 시작한다.
- 자동 정지 없음: 이탈을 감지해도 서버가 자동으로 멈추지 않는다. heartbeat로 점을 회색으로 바꾸고 이탈 알림 토스트를 띄워, 사람이 보고 수동으로 일시정지하게 한다.
- 수동 정지: 참가자만 멈출 수 있고 시간 제한이 없다. 재개는 참가자 누구나 할 수 있다. 정지 중 픽·밴·시작 요청은 거절한다.
- `/챔피언리셋`: 결과 입력 뒤 챔피언 제외 목록을 비우는 명령을 추가한다. 지금은 봇 재시작으로만 비워진다.
- 워커 배정: claude=서버, agy=화면, muse=문서(이 worktree).
- 배포 주의: 맥미니 `game_core.py`에 임시 `MAX_PLAYERS = 2`가 커밋 없이 남아 있다. 배포 전에 되돌려야 `git pull`이 충돌하지 않는다.
